# Profile Feature (Mobile)

## Overview
Handles viewing and editing user profile.

## Screens
| Screen | Description |
|--------|-------------|
| `ProfileScreen` | View profile with stats |
| `EditProfileScreen` | Edit profile information |

## Profile Sections
- Avatar & basic info
- Preferences summary
- Verification status
- Activity stats
- Settings access

## Testing
```bash
npm test -- --testPathPatterns="profile"
```
